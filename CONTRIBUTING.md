# Como contribuir

1. Crie uma branch a partir da `main` e abra um Pull Request.
2. Título do PR no padrão: `feat:`, `fix:`, `test:`, `docs:`, `ci:` ou `refactor:`.
3. A pipeline **CI** roda os testes. O PR só entra com o CI verde.
4. Peça revisão de alguém da equipe. Revisar em até 4 horas também vale ponto.

## Dicas pra pontuar (sem forçar a barra)

| Ação | Pontos |
|---|---|
| PR pequeno (até 200 linhas alteradas) | +10 |
| Pipeline verde na primeira tentativa | +5 |
| Teste novo cobrindo a mudança | +15 |
| Corrigir pipeline quebrada na `main` em até 1 hora | +20 |
| Revisar o PR de um colega em até 4 horas | +10 |

Teto de **50 pontos por pessoa por dia**. Não existem pontos negativos.
